# Platform features: external setup

This page lists the features that need something outside the repo before they work: a Clerk dashboard switch, an email
provider, a push key, a speech or AI key, a TURN or LiveKit account. Each one is off (and hidden or explained in the app)
until it is set up, and the rest of Flick keeps working. Variables are described in full in
[`operations/deployment.md`](operations/deployment.md).

Related: [`operations/deployment.md`](operations/deployment.md), [`operations/runbook.md`](operations/runbook.md),
[`security/auth.md`](security/auth.md), [`status.md`](status.md), [`ai/privacy-and-limits.md`](ai/privacy-and-limits.md),
[`features/integrations.md`](features/integrations.md).

| Feature                   | What you must set up                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Without it                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| Sign-in                   | Clerk app. Set paths `/sign-in` and `/sign-up` (home and after sign-out `/`), make username optional. Keys: `CLERK_SECRET_KEY` (API), `VITE_CLERK_PUBLISHABLE_KEY` (web). `CORS_ORIGINS` = the web origin.                                                                                                                                                                                                                                                                                 | No one can sign in.                               |
| Passkeys                  | Clerk dashboard > User & authentication > Passkeys > enable (done for this app).                                                                                                                                                                                                                                                                                                                                                                                                           | The Passkeys card in Settings, Account is hidden. |
| AI (all of it)            | At least one of `ANTHROPIC_API_KEY`, `GROQ_API_KEY_1/2`, `GEMINI_API_KEY_1/2` on the API. `AI_DAILY_LIMIT` tunes the per-user daily cap (default 200).                                                                                                                                                                                                                                                                                                                                     | AI routes answer "not configured" (503).          |
| Voice transcription       | A Groq key (Whisper).                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Transcribe button reports it is unavailable.      |
| Images and PDFs in AI     | A provider that reads them: Anthropic or Gemini. Groq models are text only and are skipped.                                                                                                                                                                                                                                                                                                                                                                                                | "Can't read this file" message.                   |
| Email-to-chat             | `INBOUND_EMAIL_SECRET` and `INBOUND_EMAIL_DOMAIN` on the API (with both set, Settings, Account shows each person their address). In Postmark (Inbound stream) or SendGrid (Inbound Parse) point the webhook at `POST https://<api>/inbound/email` and send the secret in the `x-inbound-secret` header (Postmark: custom header via a proxy or relay; SendGrid cannot set headers, so use a small relay). Mail to `<username>@<INBOUND_EMAIL_DOMAIN>` lands in that user's Saved messages. | Endpoint answers 404.                             |
| Incoming webhooks         | Nothing to set up. Group info > Webhooks > Create. `POST <api>/hooks/<id>/<token>` with `{"text": "..."}` posts as the Flick bot (30 per minute per IP). The token is shown once.                                                                                                                                                                                                                                                                                                          | -                                                 |
| Web Push                  | `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (all three). Make keys with `npx web-push generate-vapid-keys`.                                                                                                                                                                                                                                                                                                                                                                   | Notifications are only logged by the worker.      |
| Notification Reply box    | Chrome/Edge desktop only. The typed text opens the chat as a draft; the worker cannot send a reply on its own.                                                                                                                                                                                                                                                                                                                                                                             | -                                                 |
| GIFs                      | `GIPHY_API_KEY`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | GIF picker reports unavailable.                   |
| Group calls, call links   | `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` (LiveKit Cloud).                                                                                                                                                                                                                                                                                                                                                                                                                    | Group calls and links report unavailable.         |
| 1:1 calls across networks | A TURN relay: `TURN_SECRET` + `TURN_URLS` (own coturn) or `TURN_USERNAME` + `TURN_CREDENTIAL` + `TURN_URLS` (hosted). Render cannot run coturn.                                                                                                                                                                                                                                                                                                                                            | Calls work on the same network or with STUN only. |
| Uploads                   | `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`; bucket CORS for the web origin.                                                                                                                                                                                                                                                                                                                                                                                      | Uploads answer 503.                               |
| Live captions             | Nothing on the server. Browser support: Chrome, Edge, Safari (Web Speech API); not Firefox.                                                                                                                                                                                                                                                                                                                                                                                                | Option hidden.                                    |
| Camera, mic, location     | The Vercel `Permissions-Policy` header already allows `self`; the person grants the browser prompt.                                                                                                                                                                                                                                                                                                                                                                                        | Browser blocks the feature.                       |
