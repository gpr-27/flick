# Feature map

This is the master table of what the Flick app does, grouped by area. For each feature it says where to find it, whether AI is used (Yes, Optional or No), exactly how and through which endpoint, and what happens when AI is off. "AI off" means no provider key is set on the server (`GET /ai/status` returns `enabled: false`), the chat has No-AI mode on, or every provider fails.

## How to read the AI columns

- Yes: the feature does not work without a model.
- Optional: the feature works on its own and a model adds something on demand, or the feature has a non-AI fallback.
- No: plain code, a database query or a browser API. A model is never called.
- Model path: the shared provider chain. In order: Anthropic `claude-sonnet-5-5`, Groq (`openai/gpt-oss-120b`, `openai/gpt-oss-20b`, `qwen/qwen3.8-27b`, two keys), Gemini (`gemini-3.8-flash`, `gemini-3.6-flash`, `gemini-3.1-flash-lite`, two keys). Entries without a key are skipped; a failing entry is put in cooldown. Images and PDFs only go to Anthropic or Gemini. "Fast" speed (and ghost text, dictation clean-up and similar) puts Anthropic last. Speech to text is separate: Groq Whisper (`whisper-large-v3-turbo`, and `whisper-large-v3` for Indian languages), only when a Groq key is set.
- Quota: calls under `/ai/*` and `/ai/analyze` count against 200 requests per user per UTC day and 20 per minute. `/ai/transcribe`, `/ai/translate-batch` (30 per minute), `/ai/link-check`, `/productivity/*` and group AI tasks are not counted in the daily total.

## Honest gaps and partials

These are limits of the current code, checked against it.

| Area                                | Gap                                                                                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Files                               | docx and xlsx are read as plain text via mammoth and exceljs; PDF text fallback uses pdf-parse; old .doc and .xls are not supported |
| Video                               | Video files are not analysed, transcribed or translated. Transcribing a video would need audio extraction, a possible future idea   |
| Share target                        | Text and links only (GET). Files are not accepted                                                                                   |
| Send in another language            | A link above the composer, not part of the Describe bar. Translating a Describe-bar draft is not built                              |
| Translate menu                      | Only translates to English; the language dialog exists but is not opened                                                            |
| Mood and urgency badges             | Local keyword rules, with an optional AI check on tap                                                                               |
| Snooze                              | Hides a chat and its unread count on this device only; snoozing a single message is not built                                       |
| Notification digest                 | Held in browser memory only; lost if the tab closes                                                                                 |
| Birthdays                           | Not built                                                                                                                           |
| Auto-sort suggestion                | Local name matching, no AI                                                                                                          |
| Scam, impersonation and link checks | Rules in the browser; only the link check has an optional AI check                                                                  |
| Group moderation                    | The AI "flag" task is API only; muting flagged senders is not built                                                                 |
| Live captions                       | Browser Web Speech API; translating captions has no UI                                                                              |
| Notification reply                  | Replying from a push opens the chat with the text as a draft                                                                        |
| Passkeys                            | Need Passkeys enabled in Clerk                                                                                                      |
| Email-to-chat                       | Needs an inbound email provider and secret                                                                                          |
| Audio-file transcripts              | Stored and searchable, but the transcript box is drawn only under voice notes                                                       |
| Briefing                            | No AI summary; the `summary` field is always null                                                                                   |
| Mood summary                        | Reads the newest 150 messages, not strictly the past week                                                                           |
| Per-chat No-AI                      | Not checked by transcription, translate-batch, link-check, extract-reminder or the `/productivity` Saved tools                      |
